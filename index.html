Workforce Allocation & Decision Support System

Python · JavaScript · Cloudflare Workers · D1 · Pages

Staffing bids for up to 200 candidates were being ranked by hand: slow, hard to audit, and error-prone when shift preferences conflicted. I validated the ranking logic in an Excel prototype, then built a hosted web app that scores candidates across multiple shift preferences, resolves conflicts, and applies deterministic tie-breaking. 03 — Capstone Case Study

The work, before and after.

My capstone enhanced three artifacts. Each one shows how I take existing code, find its weak points, and improve its structure, security, and maintainability. The snippets below are taken from the original and enhanced code in the repository.

Engineering Code Review — Capstone Walkthrough ~8 min
01 · Software Design & Engineering
Secure C++ Client Management Refactor
Original ↗ Enhanced ↗

Removed the hardcoded password check, loaded credentials from an external config file that fails closed if missing, and masked password entry. The .env files in the repo hold demo values on purpose.

Before
// VULNERABILITY: Hardcoded password remains
if (password == "123") {
    return 1;
}
After
// Load credentials from .env
ifstream envFile(".env");
if (!envFile.is_open()) {
    cout << "Error: Could not open .env file. Access denied.\n";
    exit(1);
}
// ...password entry is masked by GetHiddenPassword()
02 · Algorithms & Data Structures
Scalable Data Handling in C++
Original ↗ Enhanced ↗

Same original program. Replaced fixed-size parallel arrays with a Client struct in a std::vector, loaded from a file, with an unordered_map index for name lookup and new add, search, and delete operations.

Before
string clients[5] = { /* ... */ };
int services[5] = { 1, 2, 1, 1, 2 };
After
struct Client {
    string name;
    int serviceType; // 1 = Brokerage, 2 = Retirement
};

vector<Client> LoadClientsFromFile(const string& filename);
// + unordered_map index for lookup by name
03 · Databases
Python/MongoDB Dashboard Enhancement
Original ↗ Enhanced ↗

The original depended on a remote course database. The enhanced data layer tests the connection with short timeouts and falls back to a mock JSON dataset, with write operations disabled in mock mode.

Before
HOST = 'nv-desktop-services.apporto.com'
self.client = MongoClient(
    f'mongodb://{username}:{password}@{HOST}:{PORT}')
After
try:
    self.client = MongoClient(uri, serverSelectionTimeoutMS=1000)
    self.collection.find_one()  # test the connection
except Exception as e:
    print("[INFO] Falling back to mock data...")
    self.use_mock_data = True
    self._load_mock_data()
